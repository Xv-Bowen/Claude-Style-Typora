Claude Style v1.2.5 底栏测量

三次测量均未复现 footer 底部偏移 10 px。临时 B 调整后，已测按钮不再垂直越出视口；但窄侧栏底部的文件夹名称仍不可见，不能据此宣称问题已整体修复。

本报告仅整理指定 A／B 测量及三张原图，不是完整主题回归，也不是完全相同旧场景的复刻。

关于这份报告 · About this report

这份报告由 dot 于 2026 年 10 月 27 日在 Linux（Debian 13.6、Xfce、X11、Typora 1.14.9）上写成：不装增强脚本，测量 Claude Style 1.2.5 浅色主题的侧栏底栏。起因是 dot 复测 1.2.4 时报告的一条问题：侧栏很窄时，底栏往下挪，被窗口底边截掉。这里原样收录，只加了这一节；报告里提到的 ZIP 没有收录，三份原始数据可以从报告里的下载链接取得。

测量结果：底栏没有往下挪，这条问题没有复现。报告里的"B"是测量时临时加进窗口的两条规则，也就是 Claude Style 1.2.6 让底栏按自己的高度排的那两条。报告里的数据和图还看得出侧栏底部那一栏在 Windows 和 Linux 上的另外三处问题，Claude Style 1.2.6 一起修了：侧栏很窄时，那一栏伸出侧栏；"新建文件"的加号和只读模式的锁叠在一起；文件夹名只在指针移到侧栏上时才显示。

This report was written by dot on 27 October 2026 on Linux (Debian 13.6, Xfce, X11, Typora 1.14.9). It measures the sidebar footer of Claude Style 1.2.5 Light, without the enhancement script, after dot's retest of 1.2.4 reported that in a narrow sidebar the footer moved down and was cut off by the window's bottom edge. It is included as written, with this section added; the ZIP the report mentions is not included, and its three raw data files can be downloaded from the links in the report. The measurement did not reproduce the problem: the footer did not move down. "B" in the report is the two rules added to the window for the test, the ones with which Claude Style 1.2.6 gives the footer its own height. The report's numbers and pictures also show three other problems of the sidebar footer on Windows and Linux, which Claude Style 1.2.6 fixes as well: in a narrow sidebar the footer ran past the sidebar, the New File plus and the Read-Only Mode lock lay on top of each other, and the folder name showed only while the pointer was over the sidebar.
